## 1. 배경 (Why)

### 1.1 현재 상황
- 해병대 역사관·박물관 소장 전사 자료를 디지털화(스캔)하는 중이며, 현재 **약 200점**이 확보되어 있다. 스캔 작업은 계속 진행 중이다.
- 자료는 있지만 후배들(장병, 간부 교육생, 일반 방문객)이 **관심을 갖고 쉽게 볼 수 있는 형태로 전달되지 못하고 있다.**
- 6·25전쟁부터 연평도 포격전까지 이어지는 해병대 전투들이 **하나의 흐름으로 연결되어 있지 않다.**

### 1.2 목표
- 해병대 전투사를 **하나의 연표로 연결**해 누구나 휴대폰이나 PC로 쉽게 탐색할 수 있게 한다.
- 같은 내용을 **교육 현장에서 바로 강의 자료로** 쓸 수 있게 한다.
- 연구관이 **익숙한 엑셀로만 작업**해도 사이트가 갱신되게 한다.

### 1.3 사용자가 얻어 가는 것
> **전투의 흐름(왜, 어떻게, 결과와 의의)을 3분 안에 이해한다.**

## 3. 핵심 시나리오

### 시나리오 A: 연표 탐색 (메인)
> 일병 김해병이 휴대폰으로 연표에 접속한다. 1950년 인천상륙작전부터 2010년 연평도 포격전까지 **대표 사진이 붙은 전투 카드**를 위아래로 넘겨 본다. "도솔산 전투"를 누르면 3줄 요약, 단계별 경과, 당시 사진, "무적해병" 칭호의 유래를 읽고 3분 만에 전투의 흐름을 이해한다.

### 시나리오 B: 교육 진행 (보조)
> 교관이 교육장 PC에서 "짜빈동 전투" 상세 화면을 열고 **[교육 모드]** 버튼을 누른다. 화면이 전체화면 슬라이드로 바뀌고, 교관은 표지 → 개요 → 경과 1~N단계 → 사진 → 의의·교훈 순서로 키보드를 넘기며 강의한다.

### 시나리오 C: 자료 반영 (작성자)
> 연구관이 새로 스캔한 사진을 이미지 폴더에 넣고 엑셀에 한 줄을 추가한다. **변환기 페이지**를 브라우저로 열어 엑셀과 이미지 폴더를 끌어다 놓으면, 사진 축소와 워터마크가 자동으로 처리된 **완성 사이트(zip)**가 내려받아진다.

## 4. MVP 범위: 핵심 기능 3개

### F1. 전투 연표 (첫 화면)
- 전투를 **시간순으로 세로 연표**에 배치한다. 휴대폰에서는 한 줄, PC에서는 좌우 교차로 배치한다.
- 각 전투 카드 구성: **대표 사진 썸네일**, 전투명, 기간, 전쟁 구분 배지, 한 줄 요약
- **전쟁 구분 필터**: 전체 / 6·25전쟁 / 베트남전 / 서해 도발 등 (엑셀 값으로 필터가 자동 생성됨)
- 검수 상태가 "초안"인 전투는 카드에 **"검수 중"** 표시를 한다.
- 카드를 누르면 F2 전투 상세로 이동한다.

### F2. 전투 상세 + 교육 모드
**읽기 모드 (기본)**
- 순서: 제목·기간·장소·참전 부대 → 요약 → 경과(3~5단계) → 사진 자료 → 의의·교훈
- 사진을 누르면 확대 보기: 제목, 설명, 연도, 자료 종류, **출처·소장처** 표시
- 이전/다음 전투로 이동하는 버튼
- 검수 상태가 "초안"이면 상단에 **"검수 중인 초안입니다"** 안내 표시

**교육 모드**
- 읽기 화면의 **[교육 모드]** 버튼으로 전체화면 슬라이드로 전환한다.
- 슬라이드 순서: ① 표지(전투명, 기간, 대표 사진) → ② 개요(장소, 참전 부대, 요약) → ③ 경과 단계별 1장씩 → ④ 사진 자료(1장씩) → ⑤ 의의·교훈
- 조작: 방향키(←/→), 스페이스, 마우스 클릭, ESC로 종료, 현재 쪽수 표시 (예: 4 / 11)
- 빔프로젝터에서 잘 보이도록 큰 글씨와 높은 대비를 사용한다.

### F3. 엑셀 → 사이트 변환기
- **설치 없이 브라우저로 여는 변환기 페이지** (`converter.html`)
- 입력: 엑셀 파일 1개 + 이미지 폴더 1개 (끌어다 놓기 또는 파일 선택)
- 처리:
  1. 엑셀의 [전투], [자료] 시트를 읽는다.
  2. **입력 검사**: 필수 항목 누락, 없는 전투ID 참조, 이미지 파일 없음, 전투당 대표 사진이 0장이거나 2장 이상인 경우를 찾아 **오류 목록을 보여 준다.**
  3. `공개여부 = X`인 자료는 **결과물에서 제외**한다.
  4. 이미지를 **웹용으로 축소**한다 (긴 변 최대 1600px, JPEG 품질 80%, 썸네일은 긴 변 480px).
  5. 모든 이미지 오른쪽 아래에 **"해병대 군사연구소" 워터마크**를 넣는다 (반투명 흰 글씨에 그림자, 이미지 너비에 비례한 크기).
  6. 사이트 파일과 처리된 이미지를 묶어 **`site.zip`으로 내려받게** 한다.
- **원본 고해상도 이미지는 결과물에 포함하지 않는다.**
- 필요한 프로그램 부품(엑셀 읽기, zip 생성)은 파일 안에 함께 넣어 **인터넷 없이 동작**하게 한다.

### 만들지 않는 것 (Out of Scope)
- 로그인, 회원 관리, 결제
- 데이터베이스, 서버
- 웹 화면에서의 직접 편집
- 검색, 사진만 모아 보는 갤러리 화면
- 인터넷 게시 (게시 위치는 추후 결정)
- 다국어(영문) 지원
- 전사자·유공자 명단, 증언 영상

## 5. 데이터

### 5.1 입력 파일 구조
```
전사자료/
├─ 전사자료.xlsx        ← 시트: [전투], [자료]
└─ images/              ← 스캔 원본 이미지 (jpg, png)
   ├─ INC-001.jpg
   ├─ DSS-001.jpg
   └─ ...
```

### 5.2 [전투] 시트: 전투 1개 = 1행

| 열 이름 | 필수 | 형식 | 예시 |
|---|---|---|---|
| 전투ID | ● | 영문·숫자 | `DSS` |
| 전투명 | ● | 텍스트 | 도솔산 전투 |
| 시작일 | ● | YYYY-MM-DD | 1951-06-04 |
| 종료일 |  | YYYY-MM-DD | 1951-06-20 |
| 전쟁구분 | ● | 텍스트 | 6·25전쟁 |
| 장소 | ● | 텍스트 | 강원도 양구군 |
| 참전부대 | ● | 텍스트 | 해병대 제1연대 |
| 한줄요약 | ● | 60자 이내 | 연표 카드에 보이는 문장 |
| 요약 |  | 3~5문장 | 상세 화면의 개요 |
| 경과1 ~ 경과5 | 경과1 ● | 단계 제목 + 내용 (`제목 | 내용`) | `6.4 공격 개시 | 북한군 제5군단의 견고한 진지에...` |
| 의의교훈 | ● | 텍스트 | "무적해병" 칭호 수여 등 |
| 검수상태 | ● | 초안 / 검수완료 | 초안 |

- 연표 정렬 기준은 **시작일**이다.

### 5.3 [자료] 시트: 이미지 1점 = 1행

| 열 이름 | 필수 | 형식 | 예시 |
|---|---|---|---|
| 자료ID | ● | 영문·숫자 | `DSS-001` |
| 파일명 | ● | images 폴더 안 파일명 | DSS-001.jpg |
| 제목 | ● | 텍스트 | 도솔산 고지를 향해 이동하는 해병대원 |
| 설명 |  | 텍스트 | 사진 설명문 |
| 전투ID | ● | [전투] 시트의 전투ID | `DSS` |
| 자료종류 | ● | 사진 / 지도 / 문서 / 유물 | 사진 |
| 연도 |  | YYYY | 1951 |
| 출처 | ● | 텍스트 (기사 사진은 언론사명·게재일 포함) | 미 해병대 역사부 / ○○신문 1951.6.21 |
| 소장처 |  | 텍스트 | 해병대 박물관 |
| 대표사진 | ● | O / X | O (전투당 정확히 1장) |
| 공개여부 | ● | O / X | O (X면 사이트에서 제외) |
| 표시순서 |  | 숫자 | 1 |

- **자료 1점은 전투 1개에만 연결된다.** 여러 전투에 반복되는 인물 사진보다 **공식 기사 사진·기록 사진** 위주로 구성한다.

### 5.4 사진 저작권 (결정사항 D1)
- 소장 판단에 따라 **시범판에 쓰는 사진은 저작권 제한이 없는 것으로 처리한다.** 별도의 "이용 조건" 열은 두지 않는다.
- 다만 **출처 표기는 모든 사진에 필수**로 하고, 공개하지 않을 자료는 `공개여부 = X`로 제외할 수 있다.
- 시범판 사진은 다음 기관의 인터넷 공개 자료 중에서 구한다: **국회도서관, 국방부 군사편찬연구소, 미 해병대(USMC), 대한민국 해병대.**
- 개발 중 사진을 내려받을 때는 **파일명, 출처, 크기 목록을 소장에게 먼저 보여 주고 승인을 받은 뒤** 내려받는다.

- 하단: "해병대 군사연구소" 표기, 자료 기준일
- 색상: 해병대 상징색(진홍 + 황색)을 강조색으로 쓰고, 본문은 읽기 쉬운 흰 바탕에 짙은 글씨를 사용한다.

## 7. 시범판 수록 내용 (초안 → 소장 검수)

| 전투ID | 전쟁구분 | 전투명 | 시기 | 주요 참전 부대 | 핵심 의의 (초안 방향) |
|---|---|---|---|---|---|
| `INC` | 6·25전쟁 | 인천상륙작전 | 1950. 9. 15. ~ | 해병대 (미 제1해병사단과 연합) | 전세 역전, 서울 수복의 발판 |
| `DSS` | 6·25전쟁 | 도솔산 전투 | 1951. 6. 4. ~ 6. 20. | 해병대 제1연대 | "무적해병" 칭호의 유래 |
| `TBD` | 베트남전 | 짜빈동 전투 | 1967. 2. 14. ~ 2. 15. | 청룡부대 제11중대 | "신화를 남긴 해병" |
| `YPD` | 서해 도발 | 연평도 포격전 | 2010. 11. 23. | 해병대 연평부대 | 북한의 기습 포격에 대한 즉각 대응 |

- 문구(요약, 경과, 의의·교훈)는 **공개된 사실을 바탕으로 개발자가 초안**을 작성하고, 모든 전투의 `검수상태 = 초안`으로 시작한다.
- 소장이 검수한 뒤 연구관이 엑셀에서 `검수완료`로 바꾸고 변환기를 다시 실행하면 "검수 중" 표시가 사라진다.
- 도구는 **4개 전투에 한정되지 않고**, 엑셀 행을 추가하면 전투 수에 제한 없이 확장된다.

## 8. 제약과 기술 방향

| 항목 | 결정 |
|---|---|
| 로그인·결제 | **없음.** 편집 권한은 엑셀 파일을 가진 연구관 3명에게만 있으므로 별도 장치가 필요 없다. |
| 서버·데이터베이스 | **없음.** HTML/CSS/JavaScript로 만든 정적 파일 묶음 |
| 실행 환경 | **연구소 PC에서 인터넷 없이** `index.html`을 더블클릭해 열린다. 데이터는 `data.js` 파일에 담는다. (`file://`에서 JSON 파일을 직접 읽지 못하는 문제를 피하기 위함) |
| 외부 라이브러리 | 엑셀 읽기(SheetJS), zip 생성(JSZip)을 **파일로 함께 넣어 오프라인 동작** |
| 이미지 처리 | 브라우저의 Canvas 기능으로 축소와 워터마크 처리 (설치 프로그램 없음) |
| 지원 브라우저 | Chrome, Edge 최신판 (군 PC 기본 브라우저 기준) |
| 반응형 | 휴대폰(360px 이상)부터 PC·빔프로젝터(1920px)까지 지원 |

## 10. 완료 기준 (Definition of Done)

- [ ] 1. 연구관이 **엑셀 1개와 이미지 폴더 1개**를 변환기에 넣으면 사이트(zip)가 만들어진다.
- [ ] 2. 모든 사진이 **웹용 크기로 축소되고 "해병대 군사연구소" 워터마크**가 들어가 있다. 원본 파일은 결과물에 없다.
- [ ] 3. 첫 화면 **연표**에 4개 전투가 시간순으로 나오고, 각 카드에 **대표 사진**이 보인다. **전쟁 구분 필터**가 동작한다.
- [ ] 4. 전투를 누르면 **상세 화면**(요약, 경과, 사진과 출처, 의의·교훈)이 나온다.
- [ ] 5. 상세 화면에서 **교육 모드**로 전환하면 전체화면 슬라이드를 방향키로 넘길 수 있다.
- [ ] 6. **휴대폰 화면과 PC 화면** 모두에서 깨지지 않는다.
- [ ] 7. **인터넷 연결 없이** 연구소 PC에서 열린다.
- [ ] 8. **`공개여부 = X`인 자료는 사이트에 나오지 않는다.**
- [ ] 9. **검수 상태가 "초안"인 전투에는 "검수 중" 표시**가 나온다.
- [ ] 10. **모든 사진에 출처**가 표기되어 있다.
- [ ] 11. (v0.2) 첫 접속 시 **대상자 선택 화면**이 나오고, 고른 대상에 따라 연표 소개·들어가는 말·의의·교훈·퀴즈가 달라진다. 다음 접속 때도 기억한다.
- [ ] 12. (v0.2) 상세 화면의 경과 중간과 끝에 **퀴즈 카드**가 나오고, 답을 고르면 정답 여부와 해설이 바로 나온다. 교육 모드에서는 퀴즈 슬라이드에서 정답을 공개할 수 있다.
- [ ] 13. (v0.2) 해당 대상자의 퀴즈를 모두 풀면 **"전사 탐구 완료" 배지**가 나온다.
- [ ] 14. (v0.2) 용어에 표시가 되어 있고, 누르면 **풀이**가 나온다. **추모 문구**가 있는 전투는 차분한 톤으로 보이고 추모 띠가 나온다.
- [ ] 15. (v0.2) 엑셀에 [퀴즈]·[용어] 시트가 없거나 대상자별 칸이 비어도 오류 없이 공통 문구로 만들어진다.

### 12.5 화면 변경
1. **대상자 선택 화면 (첫 화면)**: "어떤 분이신가요?" 카드 3장. 고른 대상은 상단 칩으로 표시되고 언제든 바꿀 수 있다.
2. **연표**: 대상자별 소개 문구, 스크롤하면 카드가 하나씩 나타나는 효과, 전투별 퀴즈 진행 표시(예: ✓ 2/2)
3. **전투 상세**: 대상자별 들어가는 말(이야기 상자), 단계가 이어진 경과, 경과 중간과 끝의 퀴즈 카드, 대상자별 교훈 제목
4. **교육 모드**: 대상자별 도입 슬라이드, 퀴즈 슬라이드(첫 "다음"에 정답 공개, 다음 "다음"에 넘어감)
5. **배지**: 해당 대상자의 퀴즈를 모두 풀면 "전사 탐구 완료" 창과 정답 수 표시
