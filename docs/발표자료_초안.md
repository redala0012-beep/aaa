## 1. 표지

- **하단**: 발표자 / 과정명 / 2026. 11.

## 2. 기획 의도: 자료는 있는데 전달이 안 된다
- **핵심 문장**: 스캔 자료 200여 점이 후배들에게 닿지 않고 있다.
- **본문**
  - 현황: 역사관·박물관 자료를 디지털화하고 있으나 자료가 흩어져 있음
  - 문제: 장병과 교육생이 관심을 갖고 볼 형태가 아님. 전투가 하나의 흐름으로 연결되지 않음
  - 목표: 한 전투의 흐름을 **3분 안에** 이해. 현장 2,000명, 온라인 10만 명 이상
- **시각 자료**: 왼쪽에 "흩어진 스캔 파일" 아이콘, 오른쪽에 "연표 화면" 캡처, 가운데 화살표

## 3. 사용자와 핵심 시나리오
- **핵심 문장**: 한 번 입력하면 읽기와 강의 두 곳에 쓰인다.
- **본문**: 3명의 사용자 흐름
  | 사용자 | 하는 일 |
  |---|---|
  | 연구관 3명 | 엑셀과 사진 폴더 정리 → 변환기 실행 |
  | 장병·방문객 | 휴대폰으로 연표를 넘기다 전투를 눌러 3분 읽기 |
  | 교관 | 같은 전투를 교육 모드로 띄워 강의 |
- **시각 자료**: 사용자 3명 → 도구 → 결과의 흐름도

## 4. MVP 설계: 기능은 3개, 뺀 것은 분명하게
- **핵심 문장**: 엑셀 입력을 택하자 로그인·서버·DB가 모두 필요 없어졌다.
- **본문**
  - F1 전투 연표 / F2 전투 상세 + 교육 모드 / F3 엑셀 → 사이트 변환기
  - 만들지 않은 것: 로그인, 결제, 서버, DB, 웹 편집, 인터넷 게시
  - 주요 결정 6가지(D1~D6) 요약
- **시각 자료**: 기능 3개를 카드 3장으로, 뺀 기능은 회색 취소선으로 표시

## 4-1. 개선 과정: 읽는 자료에서 참여하고 갱신되는 자료로 (v0.2 → v0.3)
- **핵심 문장**: "딱딱하지 않게, 일방향이 아니게, 멈춰 있지 않게"
- **본문**
  - v0.2 (소장 요청 "딱딱하지 않게, 대상자별로, 퀴즈로")
    - 장병 / 간부·교육생 / 일반 방문객별로 도입·교훈·퀴즈를 다르게 함 (사실은 공통 → 작업량 3배 방지)
    - 퀴즈 16문항, 완주 배지. 연평도는 추모 톤 유지
  - v0.3 (소장 문제 제기 "일방향이고 변화를 담지 못한다")
    - **개정 이력**과 **근거·신뢰 수준**(확인 / 추정 / 기록마다 다름) → 역사가 연구로 갱신된다는 것을 드러냄
    - **"지휘관이라면?" 결심 시나리오** → 읽기에서 판단으로. 교육 모드에서는 토의한 뒤 공개
- **시각 자료**: 대상자 선택 화면 / 퀴즈 카드 / 결심 카드(내 선택 vs 실제 결심) / 각주와 신뢰 수준 표시

## 5. 시스템 구조
- **핵심 문장**: 외부 라이브러리 0개, 인터넷 연결 0회.
- **본문**: README의 구조도(엑셀 + 사진 → 변환기[XLSX 읽기 → 검사 → 축소·워터마크 → ZIP] → site.zip → 열람자)
  - 설계 포인트 3가지: 자체 ZIP·XLSX 파서 / `data.js`로 `file://` 제약 회피 / 원본 미포함
- **시각 자료**: 구조도를 다이어그램으로

## 6. LLM 활용 과정: 코딩보다 질문을 먼저
- **핵심 문장**: "바로 기능을 정하지 말고 질문해 줘"가 가장 효과적인 프롬프트였다.
- **본문**
  - 5단계 타임라인: 인터뷰 → PRD → 구현 → 검증 → 자료 수집
  - 핵심 프롬프트 1개를 인용 (역할 지정 + 7개 질문 + 결정 포인트 + OK 후 PRD)
  - 역할 분담: LLM은 초안·구현·검증, 사람은 결정·승인·검수
- **시각 자료**: 5단계 가로 타임라인과 단계별 "사람 / LLM" 2단 표기

## 7. 디버깅과 문제 해결
- **핵심 문장**: 화면을 직접 캡처해 확인하자 "완료" 보고 뒤에 숨은 버그가 보였다.
- **본문**: 대표 사례 4건
  1. Wikimedia 429 차단 → 브라우저 경유 다운로드
  2. 세로 사진이 레이아웃을 밀어냄 → CSS Grid `min-width:0`
  3. PowerShell `$h`/`$H` 대소문자 충돌 → 변수명 변경
  4. "사진"이 실제로는 홍보 전단 → 미리보기 전수 확인 후 재분류
  5. (v0.2) 배지 창이 화면을 바꿔도 남아 있음 → 휴대폰 화면 점검 중 발견해 수정
  6. (v0.2~0.3) 검사 코드를 "넣기만" 한 상태 → 일부러 틀린 엑셀 3개로 오류 26종을 실제로 검출해 확인
- **시각 자료**: 사례 2번 수정 전·후 캡처 비교
