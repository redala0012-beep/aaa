## 2. 시나리오별 상세

### S1. 연구관: 실제 Excel 편집 → 재생성
- **수행**
  - 샘플 엑셀을 Excel에서 열어 시험용 전투 "통영상륙작전(TYS)"을 추가했습니다.
  - 사람이 입력하듯 셀에 값을 넣었습니다. 시작일은 Excel이 **날짜 형식으로 자동 변환**하도록 일반 서식 셀에 `1950-08-17`을 입력했습니다.
  - 요약 칸에 줄바꿈을 넣고, 도솔산 전투의 검수상태를 `검수완료`로 바꿨습니다.
  - [자료]·[퀴즈]·[개정] 시트에 행을 추가했습니다. 위치·정답·연도는 숫자 셀로 넣었습니다.
- **Excel 저장본의 특징**: 도구가 만든 파일과 달리 공유 문자열(sharedStrings), 테마, 날짜 일련번호(18492) 형식으로 저장됩니다.
- **결과**: 오류 0건. 날짜 `18492` → `1950-08-17`, 정답 숫자 `2` → 2번 보기, 개정 날짜 일련번호 → `2026-11-18`로 정확히 변환되었습니다.
  - 연표에서 통영상륙작전(1950.8)이 인천상륙작전 앞에 시간순으로 들어갔습니다.
  - 도솔산 전투의 "검수 중" 표시가 사라졌습니다.

### S2. 대량 자료 (사진 110장)
| 지표 | 값 |
|---|---|
| 입력 | 엑셀 1개 + 사진 110장 (원본 합계 365MB) |
| 변환 시간 | **266초** (사진 1장당 약 2.4초) → 200장이면 약 8분 예상 |
| 결과 사이트 | 36MB (원본 대비 약 10%), 파일 222개 |
| 사진 평균 크기 | 웹용 295KB, 썸네일 40KB |
| 브라우저 메모리 | JS 힙 약 38MB (안정) |
| 사진 27장 전투의 상세 화면 | 썸네일을 한꺼번에 불러와 약 1.4MB. PC·휴대폰 모두 문제 없는 수준 |
| 같은 전투의 교육 모드 | **38장 슬라이드** (사진 27장이 모두 슬라이드가 됨) → F2 |

### S3. 열람자 3종
| 대상 | 연표 제목 | 들어가는 말 | 교훈 제목 | 퀴즈 | 배지 |
|---|---|---|---|---|---|
| 장병 | 선배 해병들이 걸어온 길 | 🪖 장병에게 들려주는 이야기 | 해병의 정신 | 9문항 | ✅ "9문항 중 9개 정답" |
| 간부·교육생 | 해병대 작전사 연표 | 🎖️ 작전을 보는 관점 | 전술적 교훈 | 9문항 | ✅ |
| 일반 방문객 | 해병대 이야기 연표 | 👨‍👩‍👧 알고 계셨나요? | 역사적 의미 | 9문항 | ✅ |

- 결심 카드는 전투마다 1개씩 나왔습니다. 대상자별 도입이 없는 시험 전투(TYS)는 이야기 상자를 생략했습니다.
- 휴대폰(375px): 대상자 선택, 연표, 개정 이력, 전투 상세 5개 화면 모두 가로 넘침 없음. 용어 풀이 말풍선도 화면 안에 표시됩니다.

### S4. 교관: 교육 모드
- 3개 대상 × 5개 전투 = **슬라이드 222장**을 화면 크기별로 넘기며, 내용이 하단 조작 막대 아래로 넘치는지 자동 점검했습니다. 퀴즈·결심은 정답을 공개한 뒤 상태까지 점검했습니다.

| 화면 크기 | 용도 예 | 넘친 슬라이드 |
|---|---|---|
| 1024×768 | 구형 빔프로젝터 | 0장 |
| **1280×720** | **HD 빔프로젝터, 교육장 TV** | **23장 (최대 61px)** |
| **1366×768** | **보급형 노트북** | **13장 (최대 28px)** |
| 1920×1080 | 풀HD 모니터 | 0장 |

- 넘친 것은 모두 **4지선다·OX 퀴즈 슬라이드**입니다. 정답 해설이 하단 조작 막대와 겹치고, 위쪽 "퀴즈" 표시가 잘립니다(캡처로 확인).

### S5. 오프라인·저장 차단
- **file:// 실행**: Edge를 화면 없이(headless) 실행해 `site/index.html`을 파일 주소로 직접 열었습니다.
  - 대상자 선택 화면이 정상 표시되었습니다.
  - 간부 모드로 설정한 복사본에서는 도솔산 상세 화면의 사진, 워터마크, 신뢰 수준, 각주, 퀴즈, 결심 카드가 모두 표시되었습니다.
  - 그래서 **인터넷 없이 더블클릭으로 연다**는 완료 기준 7번을 충족합니다.
- **브라우저 저장 차단**(사생활 보호 모드나 보안 정책으로 저장소를 막은 경우): 대상자 선택, 퀴즈 채점, 결심 공개 모두 오류 없이 동작했습니다. 콘솔 오류도 0건이었습니다. 다만 새로고침하면 선택과 기록이 사라집니다(설계대로).

## 3. 발견 사항과 개선 권고

| # | 심각도 | 내용 | 원인 | 권고 |
|---|---|---|---|---|
| **F1** | **중요** | 1280×720·1366×768 화면에서 교육 모드의 퀴즈 슬라이드가 하단 조작 막대와 겹침 (최대 61px) | 글자 크기를 화면 **폭** 기준으로만 정해, 가로로 넓고 세로가 낮은 화면에서 커짐 | 퀴즈 슬라이드 글자 크기에 화면 **높이**도 반영하고, 4지선다 보기는 2열로 배치 |
| **F2** | 중간 | 사진이 많은 전투는 교육 모드가 지나치게 길어짐 (사진 27장 → 슬라이드 38장) | [자료]의 공개 사진이 모두 슬라이드가 됨 | [자료] 시트에 `교육용`(O/X) 열을 추가하거나, 교육 모드에는 표시순서 상위 몇 장만 넣기 |
| F3 | 낮음 | 대상자별 교훈 칸이 비어 공통 "의의교훈"을 보여 줄 때도 제목이 "전술적 교훈" 등 대상자 제목으로 나옴 | 제목을 대상자 기준으로만 정함 | 공통 문구를 쓸 때는 제목을 "의의와 교훈"으로 표시 |
| F4 | 낮음 | 상세 화면 대표 사진(4:3으로 잘라 보여 줌)에서 오른쪽 아래 워터마크가 일부 잘림 | 사진 비율과 화면 틀 비율이 달라 아래가 잘림 | 워터마크 여백을 키우거나 대표 사진 틀을 원본 비율에 가깝게 조정 (확대 보기와 사진 파일에는 워터마크가 온전함) |
| F5 | 낮음 | 사진 100장 이상 변환 시 진행률만 있고 남은 시간 안내가 없음 | — | "약 ○분 남음" 표시 추가 |
| F6 | 참고 | 상세 화면이 썸네일을 한꺼번에 불러옴 (27장 기준 1.4MB) | — | 현재 규모에서는 문제없음. 전투당 사진이 50장을 넘으면 지연 로딩(loading="lazy") 검토 |

## 4. 조치 결과 (F1~F4 수정 후 재시험)

| # | 조치 | 재시험 결과 |
|---|---|---|
| F1 | 교육 모드 글자 크기를 화면 폭과 **높이 중 작은 쪽**에 맞추도록 변경(`min(vw, vh)`). 4지선다 보기는 폭 900px 이상에서 2열로 배치 | 슬라이드 222장 × 화면 4종(1024×768, **1280×720**, **1366×768**, 1920×1080)에서 **넘침 0장** (수정 전 1280×720 23장, 1366×768 13장) |
| F2 | [자료] 시트에 선택 열 **`교육용`**(O/X) 추가. O로 표시한 사진이 있으면 그것만 교육 모드에 넣고, 없으면 X를 뺀 **앞의 5장**만 넣음 | 사진 27장 전투: 슬라이드 38장 → **16장**. O 2장을 지정하면 그 2장만 나옴. 실제 Excel에서 입력한 O/X도 정확히 읽음 |
| F3 | 대상자별 교훈이 비어 공통 문구를 보여 줄 때는 제목을 **"의의와 교훈"**으로 표시 (상세 화면·교육 모드 모두) | 대상자별 교훈이 있는 인천: "전술적 교훈" / 없는 시험 전투: "의의와 교훈" |
| F4 | 상세 화면 대표 사진을 자르지 않고 **전체를 보여 주도록** 변경(남는 부분은 어두운 바탕) | 세로 사진(1278×1600)도 잘리지 않고 워터마크까지 온전히 보임 |

- 변환기 검사용 엑셀 3개(오류 26종)는 수정 후에도 모두 통과했습니다.
- 대량 사진 시험 사이트와 Excel 편집 시험 사이트에도 새 화면을 적용해 다시 확인했습니다.
- F5(남은 시간 안내), F6(지연 로딩)은 현재 규모에서는 필요성이 낮아 보류했습니다.

## 5. 이번에 확인하지 못한 것
- 군 PC(국방망) 실제 환경: 보안 프로그램, 구형 브라우저 정책이 다를 수 있습니다. 시범 배포 때 1대 이상에서 확인이 필요합니다.
- 실제 빔프로젝터 화면: 해상도별 점검은 화면 크기를 흉내 내어 수행했습니다. F1 수정 뒤 실제 교육장에서 1회 확인을 권장합니다.
- 실제 스캔 원본(TIFF, 수십 MB급): 변환기는 JPG·PNG 기준입니다. TIFF는 브라우저가 열지 못할 수 있어, 스캔 시 JPG로 저장하도록 안내가 필요합니다.
